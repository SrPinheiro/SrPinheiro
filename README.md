## Sobre mim

Sou desenvolvedor FullStack.

No dia a dia, passo boa parte do tempo entre um backend em **Ruby on Rails** e interfaces em **React com TypeScript**. Gosto de acompanhar uma funcionalidade do começo ao fim: modelar os dados, escrever a regra de negócio, revisar o código e montar a interface que a pessoa vai usar de fato.
